# 1.1.4 — стабилизация рабочего пути

Стороны по Vision с временным сопоставлением; любую руку можно показать первой. 30 FPS, Back+Start только на текущий сеанс; сохранённые хваты игнорируются.

Пальцы фильтруются по capture timestamp, а не по времени прихода результата оптимизации. Старые timestamps не меняют состояние и не отправляются. При новой сессии телефона сбрасываются фильтры позы и пальцев. Устаревший кадр отбрасывается до оптимизации; просроченный результат — до изменения фильтров и ручной центровки. При восстановлении руки предсказание позиции отключено до завершения плавного возврата.

Ввод Xbox сериализует только input packet, без расчёта позы и скелета. Формат пакета совпадает с прежним. Геометрия неподвижных anchors ладони кешируется для обеих сторон.

65 тестов проходят локально. Метрики input serialization и синтетического solver сохранены рядом в benchmark-input-114.json и benchmark-solver-114.json. Solver точность на том же синтетическом примере не изменилась; время зависит от нагрузки ПК и не показывает гарантированного ускорения. Скорость сериализации не равна сетевому ping или задержке VR.

IPA и DLL соответствуют 1.1.2/1.1.3, меняется Windows bridge. Аппаратная стабильность длительного сеанса в этой подготовке не проверялась. SteamVR/VRidge не запускались. Обновляйте Windows папку целиком после закрытия прежнего bridge.
