# Центровка и постоянное подключение контроллеров\n\nУдерживайте Back + Start, чтобы выровнять луч контроллера по направлению HMD. При потере руки bridge отпускает кнопки и выставляет tracking invalid через ключи tracking cl / tracking cr в GlassVR settings. Enable cl / enable cr остаются включёнными, поэтому SteamVR сохраняет один экземпляр устройства; после возврата руки поза снова становится валидной. При завершении bridge позы переходят в invalid, устройства остаются зарегистрированными.\n\nGlassVR читает JSON настроек во время работы. Не меняйте эти ключи вручную, пока bridge запущен.\n
