# 1.1.1

Роли по порядку появления: сначала покажите только правую руку, затем добавьте левую. Vision chirality игнорируется. Если обе руки исчезли более чем на 0.7 секунды, снова покажите правую первой. Две руки при первом кадре не назначаются случайно — сначала нужна одна.

Сохранённая центровка обеих рук загружается автоматически из orientation.local.yaml рядом с конфигурацией. Из файла берутся только grip rotations; остальные параметры остаются из config.yaml. Повреждённая центровка игнорируется с предупреждением.

В Windows комплект включена последняя пользовательская центровка обеих рук; нейтральные настройки остаются в config.yaml. Для другого пользователя или изменённого крепления телефона удалите orientation.local.yaml и выполните Back+Start заново. Исходный профиль опубликован в profiles/recorded-grip.yaml. Его наличие подтверждает сохранение, а не проверку точности в шлеме.

IPA и GlassVR DLL соответствуют 1.1.0; переустановка IPA для этого обновления не требуется.
