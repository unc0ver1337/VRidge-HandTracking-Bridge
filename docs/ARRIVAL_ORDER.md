# Назначение рук по порядку появления

По просьбе пользователя Vision chirality больше не выбирает роль контроллера. Покажите сначала только правую руку, затем добавьте левую. Отслеживание сохраняет роли по движению wrist. Порядок observations в последующих пакетах и метки Vision игнорируются.

Если сразу показать две руки, программа ждёт одну руку для однозначной инициализации. Если обе исчезли более чем на 0.7 секунды, снова покажите правую первой. Когда одна остаётся в кадре, её роль сохраняется; появившаяся вторая получает свободную роль. Полностью скрытое перекрещивание по-прежнему может быть неоднозначным.

Это правило назначения, а не распознавание анатомической стороны. Одиночная левая рука после сброса будет считаться правой — это ожидаемое поведение выбранного режима.
