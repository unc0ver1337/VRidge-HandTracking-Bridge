# MPBR/v3

Little endian. Header `<4sBBHIQdHH4f` (48 bytes): MPBR, version3, count<=2, flags, sequence, session, capture host-clock seconds, width,height,fx,fy,cx,cy. Bit0: estimated intrinsics; bit1: hybrid Vision pose input. Hand `<IBbH134fId` (556 bytes): id,side,palm,reserved,21×(UV,Vision confidence),21×Core ML world XYZ,legacy position3/quaternion4/reprojection,legacy poseValid,uint64-compatible double finger source capture. Legacy pose fields are unused/zero in hybrid mode. Maximum 1160 bytes, no IP fragmentation on ordinary 1500-byte LAN MTU. Finger time0 means unavailable; source time cannot exceed pose capture. Matching v3 discovery/handshake is required; v2 clients are rejected. Sequence, session, clock sync, <=200ms packet age and latest-frame replacement remain enforced.
