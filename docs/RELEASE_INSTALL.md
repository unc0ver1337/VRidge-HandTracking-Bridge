# Установка релизов v1.0.x

## Что находится в ZIP

* `Windows/VRidgeHandBridge.exe` — консольный bridge, Python устанавливать не нужно.
* `Windows/_internal/` — библиотеки EXE; не удалять и не переносить EXE отдельно.
* `Windows/Start-Bridge.cmd` и `Windows/config.yaml` — запуск и настройки.
* `iOS/VRidge-HandTracking-Unsigned.ipa` — VRidge 2.7.8 с внедрённой библиотекой.
* `iOS/VRidgeHandTracking.dylib` — отдельно собранный твик, ARM64/iOS15+.
* `GlassVR/driver_glassvr.dll` — GlassVR с исправлением отключённой позы.
* `README.md`, `THIRD_PARTY.md`, `SHA256SUMS.txt` и документация.

## 1. GlassVR и SteamVR

1. Установите SteamVR и настройте обычное соединение VRidge с ПК.
2. Скачайте [GlassVR автора DaniXmir](https://github.com/DaniXmir/GlassVr/releases).
   Распакуйте его отдельно, откройте приложение GlassVR и установите драйвер через
   вкладку Driver → Install. Его GUI-приложение не входит в наш Windows EXE.
3. Закройте SteamVR. Сохраните копию установленного
   `SteamVR/drivers/glassvrdriver/bin/win64/driver_glassvr.dll`, затем замените её
   файлом из нашего каталога `GlassVR`. Патч исправляет valid-флаг отключённых рук.
   Не заменяйте DLL во время работающего SteamVR.
4. В GlassVR включите оба Index-контроллера. Для **position, rotation, input и
   skeletal** обеих рук выберите **UDP**. Рекомендуемые порты: левый 9002, правый
   9001. Bridge при старте сверяет их с `%APPDATA%/glassvr/settings.json`.
5. Эмуляцию HMD GlassVR выключите: HMD должен предоставляться VRidge. Отключите
   другие программы, управляющие этими же виртуальными контроллерами.
6. В `Steam/config/steamvr.vrsettings`, в секции `steamvr`, должно быть
   `"activateMultipleDrivers": true`. Сохраните резервную копию перед изменением.
7. Запустите SteamVR. После замены DLL нужен один его перезапуск.

## 2. Установка на iPhone

Нужен iPhone с задней ультраширокоугольной камерой 0.5x, iOS15+ и совместимый способ
установки изменённого приложения. **IPA unsigned:** на обычный stock iOS она не
установится без подходящей переподписи. Используйте свою поддерживаемую среду
установки или сертификат/provisioning profile. Совместимость конкретной версии
TrollStore/jailbreak/сервиса подписи нужно проверять отдельно.

Сохраните свою исходную VRidge перед установкой. Разрешите камеру, локальную сеть
и при желании системные уведомления. Библиотека работает внутри VRidge; отдельного
окна/preview в приложении нет. Задняя камера должна смотреть наружу из шлема,
в сторону рук. Предварительно убедитесь, что исходный VRidge передаёт VR-видео.

## 3. Запуск bridge

1. Полностью распакуйте ZIP в доступную для записи папку.
2. Подключите Xbox 360/XInput-контроллер к Windows.
3. Соедините iPhone и ПК с одной Wi-Fi/LAN сетью. Отключите client/AP isolation.
4. Запустите `Windows/Start-Bridge.cmd`.
5. Разрешите EXE в Windows Firewall: UDP39570 и Bonjour/mDNS UDP5353.
   В v1.0.1 все локальные IPv4-адаптеры, включая hotspot, обнаруживаются автоматически;
   оставьте `network.advertise_ip: null`, `network.bind_ip: 0.0.0.0`.
   Для Public hotspot при необходимости запустите `Windows/Allow-LAN-Firewall.ps1`
   от администратора: правила ограничены LocalSubnet. Ручной advertise_ip — только
   для намеренного ограничения одним адаптером. IP телефона вводить не требуется.
6. Откройте изменённый VRidge. Console должна показать имя iPhone, `connected`,
   FPS, reconstruction time и показатели сети. Прежде чем играть, проверьте
   обе руки в SteamVR и корректность настроек драйвера.

Для выхода нажмите Ctrl+C в консоли. Не запускайте несколько bridge одновременно.
Не удаляйте `_internal`; если EXE не запускается, установите официальный Microsoft
Visual C++ Redistributable 2015–2022 x64. Windows EXE не подписан сертификатом
издателя; проверяйте происхождение релиза и SHA256.

## 4. Xbox: одна физическая панель — две VR-руки

| Xbox | Left Index | Right Index |
|---|---|---|
| X / Y | B / меню (X) | B / меню (Y) |
| Back / Start отдельно | System | System |
| LT / RT | Analog trigger | Analog trigger |
| LB / RB | Grip | Grip |
| Левый / правый стик | Thumbstick | Thumbstick |
| LS / RS | Thumbstick click | Thumbstick click |

Выбор активной руки не нужен — ввод независим. X/Y отправляют B Index; действие
игрового меню зависит от SteamVR bindings игры. A/B Xbox пока не назначены.
При отсутствии свежей позы соответствующей руки input отпускается.

**Удерживайте Back + Start вместе:** курсоры постоянно центрируются вперёд по
взгляду HMD, учитывая реальный Index `tip` transform. Системные нажатия подавляются
после распознавания сочетания. Отпустите обе — центровка закончится; отдельная
кнопка, нажатая раньше второй, может успеть отправить System. Лучше нажимать вместе.
Поправка сохраняется рядом с config в `orientation.local.yaml`; для загрузки
сохранённой центровки запустите `VRidgeHandBridge.exe --config orientation.local.yaml`.
Обычный запуск использует исходные offsets из `config.yaml`.

## 5. Руки и скелет

Контроллер ориентируется вдоль кисти к пальцам, а не по нормали ладони. Нужна
проверка ориентации в вашей посадке телефона. `space.camera_offset_m` и
`camera_rotation_deg` задают физическое положение камеры относительно HMD.
Не используйте `space.mode: static` для движущегося телефона в шлеме.

При потере свежей качественной позы на 350ms соответствующий контроллер
остаётся подключённым в SteamVR, но его поза получает статус «нет трекинга»; другая рука продолжает работать. При возвращении руки трекинг возобновляется на том же контроллере. Bridge постоянно держит enable cl/cr включёнными и управляет отдельными tracking cl/cr. Не меняйте их вручную во время работы.

Vision даёт 21 landmark на руку. На ПК работает кинематический constrained solve
с длинами костей, camera rays, temporal priors, confidence и фильтрацией.
В GlassVR передаются пять curls и пять splays; драйвер создаёт 31-bone skeleton.
Это приближённая анимация, не независимая точная 3D-поза каждого сустава.
Игры должны поддерживать skeletal input Knuckles.

## 6. Калибровка и ограничения

Измерьте `reconstruction.palm_width_m` между index-MCP и little-MCP. Параметры
intrinsics/distortion и mount требуют реальной калибровки для высокой точности.
640×480 и capture30–60FPS не означают гарантированные 60FPS всего pipeline.

Одна RGB-камера не измеряет однозначную глубину/roll во всех ракурсах. При
перекрытии, edge-on ладони и быстрых движениях возможны отклонённые позы,
ошибки handedness и скачки оценки. Центровка задаёт нейтральную ориентацию,
но не устраняет эти физические ограничения.

Источник поз HMD — raw OpenVR tracking, чтобы преобразование игровой зоны
применялось один раз. Камера и HMD должны физически двигаться вместе.
В console latency оценивается до выхода bridge, с неопределённостью clock sync;
это не полная задержка дисплея. Haptics в обратную сторону не реализованы.

## Если не работает

* Нет iPhone: права Local Network, Firewall, Wi-Fi interface, AP isolation.
* Есть packets, нет рук: ладони должны быть со стороны задней камеры; проверить
  освещение/видимость суставов и сообщения rejected poses.
* Контроллеры замерли: проверить UDP для всех четырёх каналов, совпадение портов,
  отсутствие другого отправителя, patched DLL и её загрузку после рестарта VR.
* Есть модели, нет пальцев: Skeletal=UDP и поддержка скелета игрой.
* Меню/стики не действуют: bindings Index в игре, XInput connected, свежий tracking.
* После обновления DLL снова зависают: официальный reinstall GlassVR мог вернуть
  исходный драйвер без патча.

Для диагностического запуска: `VRidgeHandBridge.exe --config config.yaml --duration 10`.
Логи: `bridge.log` и его ротации. Подробности алгоритмов и история тестов в `docs/`.
