# Центровка только на текущий сеанс

Сохранённый хват отменён. orientation.local.yaml не загружается, grip corrections из конфигурации игнорируются. Back+Start задаёт временную поправку направления и не записывает её на диск. Можно центрировать по необходимости; автоматической центровки каждые 15 минут нет. Геометрическое преобразование камеры в SteamVR сохранено: без него невозможно передать корректную позу. iPhone передаёт реальные landmarks, а монокулярная 3D оценка остаётся приблизительной.

По документации Valve исправлена вспомогательная часть скелета: auxiliary bones соответствуют последним костяшкам, а не кончикам пальцев. Источник: https://github.com/ValveSoftware/openvr/wiki/Hand-Skeleton . Это исправление соответствия OpenVR, а не доказанный прирост точности Vision.
